How this works

Every four hours this reads the public job boards of 29 companies directly from the applicant tracking systems they already use (Greenhouse, Lever, Ashby, SmartRecruiters, Workable). Nothing is scraped from rendered pages and no listing text is republished — every link goes straight to the employer's own posting.

A role appears only if it is in the UK, is technical or creative, and looks genuinely entry level. That last check reads the posting and rejects anything asking for 2+ years, rather than trusting the "entry level" box the employer ticked. Each row shows the reason it passed, so you can tell when it gets it wrong.

Open N days is measured from when this tool first saw the role, so it is a floor, not an exact age. Reposted means the listing disappeared for at least three days and came back.
